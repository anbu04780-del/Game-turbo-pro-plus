GAME TURBO FLOATING PRO v3.0
================================

Features:
- Movable floating window over games and other apps (requires Display over other apps permission).
- Live device-wide network traffic estimate (KB/s).
- Battery percentage and RAM availability.
- Game launcher shortcuts (Free Fire / BGMI / COD Mobile if installed) and app picker.
- Battery Saver settings shortcut.
- Do Not Disturb mode toggle (requires Notification Policy access).
- Performance information dashboard.

Important:
- Android apps without root/system privileges cannot force a real CPU/GPU/FPS boost.
- Network speed shown is the phone's total traffic rate, not an internet speed-test result.
- Battery Saver and DND use Android system settings/permissions.
- DND permission can be enabled in Android settings when prompted.

Build APK:
1. Upload all project files to your GitHub repository, preserving folders.
2. Open Actions -> Build Android APK -> Run workflow.
3. When complete, open the run and download the artifact named GameTurboFloatingPro-APK.
4. Extract the downloaded artifact ZIP to get app-debug.apk.
